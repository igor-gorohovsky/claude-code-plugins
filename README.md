# Claude Code Plugins

Personal marketplace of reusable Claude Code plugins.

## Plugins

- **igoroh** — Igor's workflow skills:
  - **git** — git workflow skill: commit conventions, branching, stacked PRs with git-spice

## Install

```bash
/plugin marketplace add igor-gorohovsky/claude-code-plugins
/plugin install igoroh@igor-gorohovsky-marketplace
```
